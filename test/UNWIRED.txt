# Test files deliberately not wired into any build rule, one per line as
#   <path>  <reason>
# A reason may not start with `#` — everything from a `#` is stripped as a
# comment, so `foo.c  #include <x.h> ...` reads as a reason-less line and is
# REFUSED (loudly, which is the right call — it just costs a rewrite).
# An entry with no reason is REFUSED by tools/check_test_wiring.py — an
# unexplained exemption is the invisible-work problem the checker exists to
# remove, one level down.
#
# Empty on purpose right now: the 98 currently-unwired files are NOT exemptions,
# they are the backlog this checker was written to surface. Exempt a file only
# when "nothing runs it" is the correct end state and you can say why.
