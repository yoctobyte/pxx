# `backlog_new/` — RETIRED 2026-08-31. File nothing here.

This folder held the 2026-08-24 rule *"any NEW ticket goes here, important or
not"*, which existed to remove the friction of placing a ticket in a single
oversized `backlog/`. **That problem was solved differently and this folder was
drained.** Tickets now go to the PER-LANE backlogs named in CLAUDE.md —
`backlog-core` (A), `-nilpy`, `-tools`, `-pascal`, `-decide`, `-libs`,
`-cfront`, `-web`, `-windows`, `-docs`, `-esp`, `-umbrella` — which answer "what
is open on my lane" in one folder read, the thing the flat backlog could not do.

Kept as a signpost rather than deleted, because the name still appears in
commits and older write-ups from that week. **The rule above is no longer true;
do not obey it.** The reasoning behind the original scheme is in git history and
in `devdocs/dev/handbook-rationale.md`.
