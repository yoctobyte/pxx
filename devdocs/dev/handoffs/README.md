# Session handoff archive

Bughunt/session handoff notes, moved here from `devdocs/progress/working/` where
they'd accumulated as non-ticket clutter (working/ is a live lock on *tickets*).
These are historical session records — context from past multi-session pushes,
kept for reference, not active work. Not ranked, not gated.

**They record what a past session actually ran; they are not instructions, and
they are not maintained.** Several predate the current gating rule and say
things like "`gate.sh full` for frontend changes". **CLAUDE.md** ("THE PER-FIX
LOOP") is the authority — never widen your gate on a handoff's say-so, and do
not edit these files to match current rules: rewriting a session record
falsifies the history that is the whole point of keeping them.
