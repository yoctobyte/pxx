## The measured facts every seat needs, and the traps in them

1. **`code=` IS PAGE-QUANTISED.** `0xe8 + code` is a page multiple in every row
   measured. 3864 -> real 600 or 195; 69400 -> 67104; 20248 -> 18790. It is why
   `--no-signals`, which removes exactly 405 bytes always, read as a no-op in all
   six configurations and got reported to the owner as an anomaly. **There was
   none.** Until frankh-3f fixes it, grade on the segment with trailing zeros
   stripped.
2. **`--dce` removes ZERO bytes of data or bss.** code 1,347,352 -> 745,240,
   data 86,084 -> 86,084, bss 66,796 -> 66,796. Code and RAM are different
   problems with different passes. Cross-target DCE is the FLASH answer.
3. **There is no `.rodata` at all.** Two LOAD segments, `R E` and `RW`.
   `grep -c rodata` = 0 in `elfwriter.inc` and `defs.inc`.
4. **`--esp-profile=bare` is qemu's shape, not a chip's** — `defs.inc:2275`:
   *"qemu's esp32c3 machine models it as one RWX region."* The IDF profile keeps
   `.text` in flash and is one branch away. Say which profile beside every number.
5. **The x86-64 floor is 195 B code / 336 B data / 41,800 B bss**, verified to
   print `hello`. 32,768 of the bss is the signal alt stack, reserved even under
   `--no-signals`. The owner's remembered "267 bytes" for a no-ansistring hello
   world **still holds — it is 195.** What regressed is the DEFAULT.
6. **IDF's own SRAM cost is UNMEASURED.** Until it is, no rung can claim an
   image fits. It is rung 0 for a reason.
