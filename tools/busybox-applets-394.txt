# busybox 1.36.1 -- the 394-applet scope, as one reproducible list.
#
# WHY THIS FILE EXISTS: a TU count without its applet scope named is not
# reproducible. busybox's .config is shared mutable state, and two agents who
# each derive "the full applet set" independently get different sets and
# comparable-looking numbers. This is the scope every 394-applet measurement on
# this project was taken at; cite this file rather than a count.
#
# HOW IT WAS DERIVED (2026-09-02, frankD), and why each step removes applets:
#   1. 432 names from busybox's OWN source, not from an installed binary:
#        grep -rhoE '^//applet:.*APPLET[A-Z_]*\( *[a-z0-9_.-]+' --include=*.c . \
#          | sed 's/.*( *//' | sort -u
#      `busybox --list` from a DISTRO busybox describes the distro's build, not
#      the tree you are compiling. Debian's answers 276 here.
#   2. -11 that tools/busybox_diff.sh cannot map to a Config.in knob:
#        arch bash fsck.minix mkfs.ext2 mkfs.minix mkfs.reiser mkfs.vfat
#        nbd-client sh sysctl unit
#   3. -1  tc. networking/tc.c does not build with the HOST gcc against this
#      kernel's headers at all (TCA_CBQ_* are gone from <linux/pkt_sched.h>).
#      That is the ORACLE failing, not pxx -- an applet whose sources the oracle
#      cannot build has to come off the list.
#   4. -26 that configure accepts but that produce no applet table entry --
#      unmet dependency, a knob spelled differently in Config.in, or CONFIG_X=y
#      with every FEATURE_ under it off (tftp is exactly that):
#        chcon getenforce getsebool last load_policy matchpathcon mim nologin
#        ping6 readahead restorecon runcon runlevel selinuxenabled sestatus
#        setenforce setfiles setsebool tftp tftpd traceroute6 udhcpc6 users
#        w wall who
#      The harness REFUSES when the built set differs from the asked-for set,
#      by name and in both directions -- that refusal is what produced this
#      list, and re-deriving it means reading its output, not guessing.
#
# 432 - 11 - 1 - 26 = 394.  521 translation units at this scope.
#
# Usage:
#   tools/busybox_diff.sh --separate --targets i386 \
#     --applets "$(grep -v '^#' tools/busybox-applets-394.txt | tr '\n' ' ')"
